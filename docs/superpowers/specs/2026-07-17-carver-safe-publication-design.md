# Безопасная публикация CARVER из Windows Studio

Дата: 2026-07-17

## Цель

Довести один генератор CARVER из предоставленного Excel-прайса до проверенного
публичного XML-фида, а затем до объявления Avito, не публикуя закупочные цены,
не завязывая приложение на путь конкретного компьютера и не повреждая предыдущий
рабочий фид при сетевой или серверной ошибке.

## Подтверждённые входные данные

- Исходный файл: `Прайс_генераторы_CARVER_фото_15.07.xlsx`.
- В файле один лист `Прайс склада`, 23 товарные строки и 23 встроенных изображения.
- Розничная цена: закупочная цена плюс 7 процентов.
- Итог округляется вверх до ближайших 10 рублей.
- Целевой путь на Avito: `Для дома и дачи / Ремонт и строительство / Инструменты /
  Силовая, строительная техника и комплектующие / Устройства электропитания /
  Генераторы`.
- Контрольный товар: `PPG-1900IS`. Три устройства ATS не входят в первую
  публикацию, потому что для них конечный тип товара может отличаться от генераторов.

## Выбранная архитектура

### Локальный прайс

Studio получает файл через тематический диалог выбора. Файл копируется в
`<bridge_root>/runtime/carver/current.xlsx`; каталог `runtime/` исключён из Git.
Исходный файл пользователя не изменяется. В локальный YAML записывается абсолютный
путь к скопированному файлу, поэтому существующий `carver_xlsx`-источник продолжает
работать без нового слоя конфигурации. На другой машине пользователь выбирает прайс
один раз заново.

Перед заменой текущего прайса Studio разбирает выбранный файл и проверяет:

- лист называется `Прайс склада`;
- найдено 23 строки с моделью и положительной ценой;
- у каждой строки есть стабильный supplier SKU;
- встроенные изображения однозначно сопоставляются строкам по номеру строки Excel.

Невалидный файл не копируется и не меняет рабочую конфигурацию.

### Цена

`avito-bridge` получает отдельную реализацию режима `up_to_10`:

1. рассчитывает `raw = cost * 1.07`;
2. округляет `raw` вверх до числа, кратного 10;
3. возвращает целое число рублей.

Существующие режимы `none` и `up_to_90` сохраняют прежнее поведение. Выбор
`up_to_100` также получает собственную реализацию, чтобы пункты интерфейса не
маскировались под `up_to_90`.

Для `PPG-1900IS`: `22 786 * 1.07 = 24 381.02`, цена фида — `24 390` рублей.

### Категория

Навигационный breadcrumb сайта не считается доказательством имён XML-полей.
Первый кандидат для Автозагрузки формируется по существующей трёхуровневой модели:

- `Category`: `Ремонт и строительство`;
- `GoodsType`: `Инструменты`;
- `GoodsSubType`: `Генераторы`.

Полный breadcrumb сохраняется в комментарии профиля для аудита. Публикация
масштабируется только после того, как XML-валидатор или отчёт загрузки Avito
подтвердит категорию. При коде ошибки категории меняются только значения тегов,
без изменения парсера, цен или фотографий.

### Формирование и публикация XML

Прайс CARVER является локальным Windows-источником, поэтому XML строится в Studio.
До сетевого вызова приложение проверяет:

- построено хотя бы одно объявление;
- количество `<Ad>` совпадает с `ads_built`;
- у каждого выбранного объявления есть `Id`, `Title`, `Description`, `Price`,
  категория и хотя бы одно изображение;
- `PPG-1900IS` имеет цену 24 390 рублей;
- в контрольном фиде отсутствуют ATS и остальные невыбранные позиции.

На VPS файл сначала загружается как
`/opt/oasis/staticfiles/.avito-feed-carver.xml.tmp`. Сервер повторно разбирает XML
и проверяет наличие `<Ad>`. Только после успешной проверки выполняется атомарный
`mv` в `/opt/oasis/staticfiles/avito-feed-carver.xml`. Ошибка загрузки или
валидации оставляет предыдущий публичный файл без изменений.

Публичный URL: `https://splithome.ru/static/avito-feed-carver.xml`.

### Контрольная публикация

Первый фид содержит только `PPG-1900IS`. Его встроенное изображение загружается в
существующее хранилище `manual-photos`, URL записывается в локальный профиль.
Автозагрузка Avito подключается к публичному URL только после HTTP 200 и локальной
проверки XML.

Расширение выполняется ступенями:

1. один генератор;
2. пять генераторов после статуса `active` первого;
3. все подходящие генераторы после чистого отчёта пяти.

ATS остаются выключенными до отдельного подтверждения их конечной категории.

## Ошибки и восстановление

- Неверный Excel: показать точную причину, сохранить прежний прайс и YAML.
- Ошибка извлечения фото: не выбирать товар для публикации автоматически.
- Ошибка генерации XML: не выполнять SSH-вызов.
- Ошибка SSH или серверной проверки: не заменять публичный XML.
- HTTP 404 после публикации: считать операцию неуспешной и не запускать загрузку Avito.
- Ошибка категории Avito: оставить один контрольный товар, исправить только теги
  категории и повторить контрольную загрузку.

## Тестирование

### `avito-bridge`

- расчёт `+7%` с `up_to_10` на реальных ценах прайса;
- независимое поведение `none`, `up_to_10`, `up_to_90`, `up_to_100`;
- парсинг предоставленного контракта CARVER;
- конфигурация категории и публичного пути.

### `avito-studio`

- невалидный выбранный файл не заменяет текущий;
- валидный файл копируется в `runtime/carver/current.xlsx` и сохраняет путь;
- локальный фид проверяется до SSH;
- временный публичный файл атомарно заменяется только после серверной проверки;
- ошибка проверки не вызывает `mv`;
- readiness блокирует товар без фото, категории или подтверждённой цены.

### Ручная проверка

- открыть CARVER, выбрать предоставленный Excel и обновить каталог;
- убедиться, что видны 23 строки;
- загрузить фото и выбрать только `PPG-1900IS`;
- проверить цену 24 390 рублей;
- опубликовать XML и получить HTTP 200 по публичному URL;
- проверить единственный `<Ad>` перед подключением Автозагрузки.

## Критерий завершения

Минимальный технический результат: публичный валидный XML содержит ровно один
`PPG-1900IS` с ценой 24 390 рублей и изображением, а тесты обеих программ зелёные.
Продуктовый результат: отчёт Avito показывает это объявление как `active`; только
после этого разрешено расширение списка публикации.

## Основные риски

1. XML-теги категории отличаются от breadcrumb сайта. Снижение риска: один товар,
   проверка валидатором/отчётом, отсутствие массового запуска до `active`.
2. Новый прайс имеет другую структуру. Снижение риска: проверка до замены рабочего
   файла и сохранение последней корректной копии.
3. Сетевой сбой оставляет частичный XML. Снижение риска: временный файл, серверный
   разбор и атомарный `mv`.
