# Массовое изменение кондиционеров

## Цель

Через Avito Content Studio одним локальным действием отключить указанные серии кондиционеров и снизить текущие цены остальных включённых кондиционеров на заданный процент. Внешняя публикация остаётся отдельным подтверждаемым шагом.

## Утверждённый сценарий

- Работает только в профиле «Кондиционеры».
- Пользователь указывает серии для отключения и процент снижения цены.
- Для текущей задачи отключаются `XIGMA JETPRO` и `Ballu Aura`.
- Скидка 5% применяется один раз к каждой модели во всех остальных сериях, которые включены для публикации после отключения.
- Новая цена считается от текущей рассчитанной цены модели: `round(current_price * 0.95)`.
- Уже выключенные серии не получают ручных цен.
- Действие сохраняет изменения только в локальном YAML. Отправка на сервер и в реальный фид Avito выполняется существующей командой «Опубликовать изменения» после отдельного подтверждения.

## Интерфейс

В каталоге кондиционеров появляется действие «Массовое изменение». Диалог содержит:

- поле со списком серий для отключения, по одной строке в формате `Бренд Серия`;
- процент снижения цены;
- предварительную сводку количества отключаемых серий и изменяемых моделей;
- кнопки «Отмена» и «Применить локально».

Если серия не найдена среди текущего каталога или уже отключена, диалог сообщает об этом и не скрывает результат.

## Данные и расчёт

Строка каталога хранит коды и текущие цены всех входящих в серию моделей. При применении операции:

1. серии сопоставляются без учёта регистра по паре «бренд + серия»;
2. найденные серии выключаются;
3. для каждой модели остальных включённых серий создаётся `manual_price_override` с новой целой ценой;
4. конфигурация сохраняется один раз после полного успешного расчёта.

Повторное применение той же скидки считается новым осознанным действием и снова уменьшает уже текущие цены; диалог явно показывает это перед сохранением.

## Ошибки и безопасность

- Ноль, отрицательное значение и скидка 100% или больше отклоняются.
- Модели без корректной текущей цены пропускаются и учитываются в сводке.
- При отсутствии подходящих включённых моделей ничего не сохраняется.
- Профили венков, бытовой техники и CARVER не меняются.
- Операция не запускает деплой и не взаимодействует с Avito самостоятельно.

## Проверка

- Модульные тесты расчёта цены, выбора только включённых оставшихся серий, отключения целей и поведения при неизвестной серии.
- Тест сохранения всех модельных кодов, а не только представителя серии.
- Запуск набора тестов Avito Studio и сборка Windows-приложения.
- Практическая проверка через интерфейс: после операции `XIGMA JETPRO` и `Ballu Aura` выключены, количество выбранных серий уменьшено на две, а сводка публикации содержит изменения цен.
