# Единый стиль Avito Content Studio

Любое новое окно, кнопка или функция обязаны выглядеть частью той же системы, что страницы
«Обзор» и «Каталог». Стандартная серая форма Qt без фирменной композиции не допускается.

## Обязательный контракт окна

- фон `dialogPage` с общим светлым градиентом;
- шапка `dialogHeader` с `dialogTitle` и `dialogSubtitle`;
- содержимое в карточках `dialogCard` / `formSection`;
- подвал `dialogFooter`, отделённый от содержимого;
- ровно одно главное действие с `role="primary"`;
- вспомогательные действия используют `secondary` или `ghost`;
- зелёный предназначен для успеха, красный — для ошибки/опасного действия;
- локальные `setStyleSheet()` вне `theme.py` запрещены.

## Элементы

- карточки и секции: `ui_components.Card` / `FormSection`;
- шапка и подвал: `dialog_header()` / `dialog_footer()`;
- кнопки: `role_button()` или `set_button_role()`;
- выбор файла: тематический `get_open_file_name()`;
- нативный `QFileDialog.getOpenFileName()` в рабочих формах запрещён;
- вкладки используются как сегментированный переключатель режима;
- прогресс, предупреждения и подтверждения наследуют глобальную тему.

Правила являются частью архитектуры приложения и проверяются UI-contract тестами.
